# Ever After — Daniel & Sophia Wedding Invitation Website

A luxury digital wedding invitation and celebration hub created for **Daniel Hayes & Sophia Montgomery** (December 20, 2026).

Designed with a high-end editorial wedding magazine aesthetic inspired by *Vogue Weddings* and *Kinfolk*.

---

## 💍 Highlights & Features

- **Welcome / Opening Screen:** An interactive full-screen stationery card with a wax seal stamped with the couple's monogram (`D & S`) and smooth opening animations.
- **Hero Section:** Editorial cover portrait with arch framing, couple's names in serif typography, and romantic vows.
- **Live Countdown Timer:** Counting down days, hours, minutes, and seconds to December 20, 2026 at 3:30 PM EST, with 1-click **Add to Google Calendar** and **Download iCal (.ics)** integrations.
- **Our Love Story:** Poetic alternating timeline from their rainy afternoon encounter in SoHo to the Tuscan proposal in Florence.
- **Wedding Details:** Separate luxury cards for **The Holy Ceremony** (The Glass Conservatory) and **The Evening Celebration** (The Grand Ballroom & Orangery) at Willowbrook Manor, Greenwich, CT, with direct Google Maps integration and address copy.
- **Order of Events:** Day-of wedding schedule from 3:00 PM guest arrival to midnight.
- **Wedding Entourage:** Filterable directory of parents, principal sponsors, bridal party, groomsmen, and flower girls.
- **Photo Gallery & Lightbox:** Responsive grid with category filters (*All*, *Engagement*, *Travels*, *Candid*) and full-screen Lightbox with keyboard navigation (`Escape`, `ArrowLeft`, `ArrowRight`).
- **Visual Dress Code Guide:** Black Tie Optional attire guide with swatches for Sage Green, Champagne Gold, Warm Taupe, Dusty Rose, and Midnight Navy.
- **Interactive RSVP Form:** Complete validation, guest count selection, dietary preferences, song request, confetti burst celebration, and local persistence (`localStorage`) with CSV export.
- **Real-time Guestbook:** Allows guests to post well wishes and blessings directly to the board.
- **Accommodations & FAQ:** Hotel room blocks, shuttle schedules, wishing well registry, and interactive FAQ accordion.
- **Printable Keepsake Card:** Printable formal invitation card (`window.print()`) optimized for stationery printing.
- **Ambient Romantic Synthesizer:** Self-contained acoustic harp and celeste chord cycle synthesizer using the Web Audio API with play/pause controls.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ColumbresJefrey/wedding.git
cd wedding

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
